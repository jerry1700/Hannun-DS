# 과거 기사 데이터셋 프로파일

SSAFY 가 준 과거 기사 CSV 두 개를 `scripts/profile_dataset.py` 로 한 번씩 훑은 결과(2026-08-28).
DE 가 이 CSV 를 공통 기사 JSON(`source_type=DATASET`)으로 바꾸고, 우리는 그 JSON 을 받는다.
그래서 이 문서는 두 가지에 쓴다 — DE 와 변환 규칙을 맞추는 근거([계약](../../../docs/contracts/de-to-ds-article-json.md)),
그리고 티켓 100 전처리 규칙의 근거.

| 파일 | 크기 | 행 | 언론사 | 기간 |
|---|---|---|---|---|
| `ssafy_dataset_news_2023.csv` | 4.36 GB | 2,005,321 | 34 | 2023-01-01 ~ 12-31 (언론사별로 반년만 있는 곳 다수) |
| `ssafy_dataset_news_2024_1st_half.csv` | 1.67 GB | 829,421 | 19 | 2024-01-01 ~ 06-30 |

두 파일은 사용자 로컬(`Desktop/`)에 있고 저장소에는 넣지 않는다.

## 형식

- 구분자 `|`, UTF-8(BOM 없음), 큰따옴표 인용. 필드 수가 어긋난 행은 두 파일 모두 0.
- `article` 안에 줄바꿈이 그대로 있다(2023 기준 99.9%). 줄 단위로 읽으면 안 되고 CSV 파서를 써야 한다.
- 컬럼 8개. 정렬은 날짜순이 아니라 **언론사별 블록**이다.

| 컬럼 | 예 | 공통 JSON 대응 | 비고 |
|---|---|---|---|
| `company` | `연합뉴스`, `KBS뉴스`, `한겨례` | `publisher_name` | `publisher_id` 없음. "한겨례"는 데이터셋의 오타 그대로 |
| `title` | | `title` | 깨진 HTML 엔티티 잔재 2.4% / 8.5% |
| `link` | `https://www.khan.co.kr/article/2026…` | `url` | `article_id` 없음 → DE 가 해시 |
| `published` | `2023-06-23 16:43:33` | `published_at` | 형식 4종, 타임존 없음(KST) |
| `category` | `사회`, `증권`, `mobile`, 빈값 | `category` / `category_str` | 언론사 자체 분류. BE enum 아님. 값 안에 `\|` 가 있는 경우도 있음(`사회\|사건·사고`) |
| `reporter` | `김동훈 기자` | `author` | 빈값 16% / 17% |
| `article` | | `content` | 빈값 2.4% / **8.0%** |

언론사 무관 규칙(HTML 태그, 엔티티, 사진 출처, 이메일)만 건다.

## DE 와 맞출 것

[계약 문서](../../../docs/contracts/de-to-ds-article-json.md) 에 정리. 요지:
`publisher_id` 부여표, `published` 4형식 + KST, `category` 처리, 빈 본문 11만 건, `link` 중복 8.6만 건,
그리고 **URL 정규화 규칙** — 쿼리스트링을 전부 지우면 `contents.html?article_no=…`(디지털타임) 같은 URL 은
기사 번호가 사라져 모든 기사가 같은 `article_id` 를 받는다.
