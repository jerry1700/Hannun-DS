# S15P21E105-89 · 이슈 군집화 (STEP 3)

| 항목 | 내용 |
|---|---|
| 상태 | 창 단위 전체 군집 구현·검증 완료. 15분 증분(102)·이슈 ID 승계(97)는 별도 티켓 |
| 결과물 | `src/hannun/clustering/` (clusterer·store·pipeline·cli), CLI `hannun-cluster`, `issue/` 테이블 |
| 관련 티켓 | 11(embedding 테이블이 입력), 102(15분 증분), 97(issueId 승계), 104(골드셋 채점), 93(-1 구제는 STEP 4) |

## 1. 티켓 해석

48h 창의 대표 기사 벡터를 "같은 사건을 다룬 기사 덩어리"(이슈)로 묶는다. 알고리즘은
설계 단계에서 전수 비교로 정한 UMAP+HDBSCAN 그대로 — 이슈 개수를 미리 정할 필요가
없고, 어느 이슈에도 못 드는 기사를 노이즈(-1)로 정직하게 남긴다(-1 은 지우지 않고
STEP 4 가 구제·판별한다).

## 2. 구조

```
embedding/ (대표 기사 벡터, 384차원 정규화)
  → UMAP: 5차원 축소, cosine 이웃            ← 고차원에서 HDBSCAN 이 밀도를 못 재는 문제
  → HDBSCAN: min_cluster_size=3              ← 파일럿 최소 이슈(북미 3건)에 맞춘 시작값
  → issue/ 테이블: issue_local(-1=노이즈), issue_size, 창 정보
```

## 3. 결정과 이유

| 결정 | 이유 |
|---|---|
| 창 = 날짜 범위 통째 (dedup 과 동일) | 쪼개면 경계를 넘는 이슈를 놓친다 |
| `issue_local` 은 창 내부 임시 번호 | 서비스 issueId 는 재계산마다 흔들리면 안 됨(API 커서) — 승계는 티켓 97 |
| 모델 섞인 창은 즉시 에러 | 다른 모델의 벡터가 섞이면 거리가 의미를 잃는다. 조용히 이상한 이슈를 내느니 멈춘다 |
| UMAP seed 고정(단일 스레드 감수) | 재현성 > 속도. 창 수만 건은 어차피 분 단위 |
| umap-learn 은 `clustering` 선택 그룹 | numba 가 무겁고 3.14 미지원 — embedding 과 같은 이유·같은 방식 |
| 테스트는 reduce_fn 주입 + umap_dims=0 | umap 설치 없이 2차원 합성 벡터로 파이프라인 검증 |

HDBSCAN 특성 메모: 창의 모든 기사가 한 덩어리면 루트 클러스터를 이슈로 내지 않고 전부
노이즈가 된다 — 실제 뉴스 창엔 이슈가 항상 여럿이라 무해하지만 초소형 입력에선 주의.

## 4. 검증

**파일럿 30건 (팀 6명 합의 라벨, e5 인코딩 → UMAP → HDBSCAN 전체 파이프라인):**

| 기준 | ARI |
|---|---|
| 파일럿 합의(이슈 4개) | 0.850 |
| **가이드 확정 규칙 적용(국면 통합, 이슈 3개)** | **1.000** |

유일한 차이가 한미훈련↔북미 통합인데, 이는 가이드가 "같은 국면 통합"으로 정한 방향과
일치. 노이즈 0, umap_neighbors 5/10/15 모두 동일 결과(파라미터에 둔감).

**실데이터 2023-01-02 (대표 5,358건):** 이슈 509개, 노이즈 757건(14%), 처리 수 분.

- 정치·사회 이슈는 깨끗하게 묶임 — 이재명·문재인 봉하 회동 35건/17개 언론사,
  전장연 지하철 시위 75건/16곳, 이태원 국조 연장 협의 5건 등
- 이태원 관련 15건은 이슈 6개로 분산 — 확인 결과 대부분 **올바른 세부 분리**
  (특수본 수사 / 전시 검열 논란 / 총리 발언 / 신년사 논평은 실제로 다른 사안).
  국조 연장(212)과 이재명 국조 발언(222)이 갈린 것만 "같은 국면 통합" 경계 —
  파일럿부터 알려진, HDBSCAN 이 가이드보다 잘게 내는 특성(104 채점 시 부분 점수)

## 5. 알려진 한계 — 정형 기사가 초대형 가짜 이슈를 만든다

최대 "이슈"가 서울경제 시황 자동 기사 483건(`<유>…매도잔량`, `<코>…신저가`), 2위도
같은 부류 122건. 지역별 코로나 집계(41건)·한파 날씨(69건)도 유사 성격. 템플릿 문체가
벡터 공간에서 빽빽한 덩어리를 만드는 구조적 현상으로, dedup 검수의 출구조사 오탐과
같은 뿌리다. **STEP 4(정형 기사 판별·품질 필터)의 필요성을 실측으로 확증** — STEP 3
에서는 고치지 않는다(문턱을 만지면 진짜 이슈가 다친다).
