## 1. 후보 3개와 선정 논리

"가장 좋은 모델"이 아니라 우리 제약(EC2 t3.xlarge 4 vCPU CPU 전용, 15분 주기, 용도는 검색이
아니라 군집화)에서의 최선을 찾는 실험이라, 결정 공간을 대표하는 세 슬롯을 골랐다.

| 슬롯 | 모델 | 이유 |
|---|---|---|
| 기존 제안 검증 | jhgan/ko-sroberta-multitask (768d) | 기획 단계 제안. 검색 벤치 최하위지만 용도가 STS 계열이라 실험 없이 못 버림 |
| 운영 최적 가설 | dragonkue/multilingual-e5-small-ko-v2 (384d) | 경량 최상급, 차원 절반 → 저장·UMAP 비용 절반 |
| 품질 상한 기준점 | nlpai-lab/KURE-v1 (1024d, bge-m3 기반) | 한국어 검색 1위. 경량 모델이 이것에 얼마나 근접하는지 재는 자 |

KoE5·e5-base 급은 첫 판에서 뺐다(중간 체급 — 위 둘이 갈리면 2차 후보). API 임베딩은 기획
때 반대 확정(외부 전송·건당 비용).

## 2. 지표 — 뒤로 갈수록 서비스 목적에 가깝다

| 지표 | 방법 | 무엇을 재나 |
|---|---|---|
| 속도 | 2023 실측 하루치를 4스레드(EC2 모사) 배치 인코딩, 문서/초 | 15분 주기·백필 감당 능력 |
| 분리력 | STEP 1 검증기가 확정한 중복 쌍 vs 무작위 쌍의 코사인 간격 | 같은 글을 붙이는 기본기. 간격이 겹치면 탈락 |
| 이슈 재현 | 파일럿 30건을 군집화(합의 이슈 수로 응집 군집), 6명 중 4명 이상 합의 쌍으로 만든 정답과 ARI | 서비스 목적(이슈 묶기) 그 자체 |

입력은 STEP 2 설계대로 "제목 + 정제 본문 앞 500자". e5 계열은 `passage: ` 접두어 필수.

## 3. 결과 (2026-09-01, 2023-03-15 하루치 2,000건 · 확정 쌍 98 · 파일럿 30건)

| | ko-sroberta | **e5-small-ko-v2** | KURE-v1 |
|---|---|---|---|
| 차원 | 768 | **384** | 1024 |
| 속도(경합 중)¹ | 3.4건/s | **6.8건/s** | 1.0건/s |
| 중복 쌍 코사인 p10 | 0.949 | 0.955 | 0.961 |
| 무작위 쌍 코사인 p90 | 0.310 | 0.481² | 0.358 |
| 분리 간격 | 0.639 | 0.475² | 0.603 |
| 파일럿 ARI | 0.877 | 0.877 | 0.877 |

¹ dedup 병렬 실행과 CPU 를 나눠 쓰며 측정 — 절대값은 과소, 모델 간 비율은 유효. 무경합 재측정 예정.
² e5 계열은 코사인이 전체적으로 위로 몰리는 특성(무작위 쌍도 0.48). 절대 간격 비교는 불공정하고,
  세 모델 모두 중복·무작위 분포가 겹치지 않는다는 것(오버랩 0)이 중요하다.

## 4. 이슈 재현 혼동 분석 — 셋 다 같은 곳에서, 사람이 갈린 곳에서만 갈렸다

세 모델의 ARI 가 동점(0.877)인 것은 우연이 아니라 **혼동 지점이 하나뿐이고 셋이 같기** 때문.
조희대(9건)·용산 청년주택(8건)은 완벽 재현. 유일한 차이는 한미훈련 축소 ↔ 북미 정상회담 경계 —
사람은 "훈련 / 정상회담"으로, 모델은 "정상외교 메시지 / 훈련 축소 실무·반응"으로 나눴다.
이 경계는 파일럿에서 팀도 3:3 으로 갈렸던 곳이고, 라벨 가이드가 확정한 **"같은 정치적 국면 통합"**
규칙(한미훈련+북미 = 한 이슈)을 적용하면 한 이슈 내부의 세부 구분이라 오답이 아니다.
→ 확정 가이드 기준으로는 세 모델 모두 사실상 완벽 재현. 품질로는 후보를 가를 수 없다.

## 5. 잠정 결론 — e5-small-ko-v2

품질(분리 오버랩 0, ARI 동점)이 같으므로 운영 비용이 결정한다: 속도가 KURE 의 **7~10배**,
차원 384 로 임베딩 테이블·UMAP·48h 창 메모리가 KURE 의 1/3. 하루 3만 건 기준 KURE 는
EC2 에서 3~4시간, e5 는 30분 안팎으로 추산 — 15분 주기 설계와 양립하는 것은 e5 뿐이다.

확정 전 남은 확인: 무경합 속도 재측정(2023 실측 종료 후).
