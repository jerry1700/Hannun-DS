# S15P21E105-10 · 중복 검출 (STEP 1)

| 항목 | 내용 |
|---|---|
| 상태 | 구현·실데이터 검증 완료, MR 대기 |
| 결과물 | `src/hannun/dedup/` (exact·candidates·verify·groups·pipeline·store·cli), CLI `hannun-dedup`, `gold/` 옆 `dedup/` 테이블, 테스트 파일 5개(전체 149개 통과) |
| 관련 티켓 | 100(정제본이 근사 비교 입력), 103(중복 라벨 `동일`/`재작성` — 채점은 `동일`만), 104(골드셋 채점), 89(재작성 묶기는 STEP 3), 11(임베딩은 대표 기사만) |

## 1. 티켓 해석

STEP 1 은 **같은 글**만 접는다 — 통신사 전재, 같은 기사 재발행처럼 글자 수준에서 같은 것.
같은 사건을 다시 쓴 기사(재작성)는 일부러 접지 않는다: 그건 STEP 3 가 임베딩으로 묶을 대상이고,
여기서 접으면 DS2 관점 대조의 재료가 사라진다. 103 가이드의 중복 라벨 2단계와 정확히 대응한다.

## 2. 네 관문

| 관문 | 입력 | 방법 | 문턱 |
|---|---|---|---|
| 0. 자격 | 정제본 길이 | `min_fold_len` 미만은 판정에서 제외해 단독으로 | 100자 |
| 1. 완전 중복 | **원문** `content` | SHA-256 동일 그룹 | — |
| 2. 후보 | 정제본 | char 4-gram → MinHash(128) → 이중 LSH | Jaccard 0.7 + containment 0.7 |
| 3. 검증 | 정제본 | TF-IDF `char_wb(3,4)` | 코사인 ≥0.95 또는 containment ≥0.90(짧은 쪽 ≥300자) |
| 4. 그룹 | 확정 쌍 | 별(star) 그룹 — 대표와 직접 확정된 쌍만 접고, 나머지는 자기들끼리 재그룹 | 상한 30 |

대표 선정: 최초 발행 → 본문 긴 것 → `article_id` (실행마다 같은 대표가 나오게 정렬 고정).
창은 날짜 범위 통째 — 쪼개서 두 번 돌리면 자정 경계를 넘는 쌍을 놓친다.

## 3. 결정과 이유

| 결정 | 이유 |
|---|---|
| 완전 중복은 원문, 근사 중복은 정제본 | 전재는 저작권 꼬리까지 같아 원문 해시로 걸린다. 근사 비교에서 원문을 쓰면 매체별 꼬리 차이가 유사도를 깎아 불공정 |
| LSH 인덱스를 둘(Jaccard + LSHEnsemble) | Jaccard 단독은 길이 차가 큰 포함 관계(속보 → 종합 기사)를 구조적으로 놓침 |
| 후보 단계 containment 문턱 0.7 (0.9 아님) | 실측에서 LSHEnsemble 0.9 가 진짜 containment 1.0 쌍도 놓쳤다(파라미터 스윕으로 확인). 후보는 넓게 잡고 검증이 거른다 |
| 검증은 코사인·containment 두 갈래 | 코사인은 대칭이라 길이 차에 약하고, containment 는 짧은 글에서 우연히 높아짐 — 그래서 짧은 쪽 300자 조건을 붙임 |
| `min_fold_len=100` | 실데이터 오탐 3건 전부가 본문이 저작권 꼬리뿐인 기사(속보·포토·영상). 접을 근거인 본문이 없으면 접지 않는 게 안전한 기본값. 크롤러 발행 기준·정제 `short` 기준과 같은 값 |
| 그룹 상한 30 + 별형 재분할 | 검증을 통과한 쌍이라도 사슬로 이어지면 다른 기사끼리 한 그룹이 될 수 있음. 상한 초과 시 대표의 직접 이웃만 남기고 재분할 |
| **연쇄(chained) 전파 접힘 제거** (2026-09-02) | 1월 실측 표본 280쌍 전수 검수에서 연쇄로만 이어진 접힘의 정탐률이 **35.7%** — 직접 검증된 접힘(코사인 91.4 · containment 95.7 · sha256 88.6%)과 격이 달랐다. 별 그룹을 모든 그룹에 적용해 접힘은 전부 대표와 직접 확정된 쌍으로 한정 (가중 정탐률 89.5% → 약 92% 예상, 접힘 감소는 4.3%뿐) |
| 문턱은 전부 설정 dataclass | CODE_STYLE — 재실험·튜닝 시 코드 수정 없이 값만 바꾼다 |

## 4. 실데이터 검증 (표본 5,105건, 2023-01~2024-06)

| 항목 | 값 |
|---|---|
| 판정 제외 (정제본 <100자) | 124 (2.4%) |
| 후보 쌍 | 34,313 |
| 검증 확정 / 기각 | 2 / 34,311 |
| 접힘 | 2 (containment 2, 코사인·sha256 0) |

- `min_fold_len` 도입 전 접힘 7 중 **의미상 오탐 4** — 전부 문턱 탓이 아니라 "본문이 본문이 아닌 기사"였다.
  본문이 저작권 꼬리 한 줄인 속보·포토 쌍 3건(sha256), 정형 기사 1건(containment). 도입 후 앞 3건 소멸.
- 남은 접힘 2건: 중앙일보 재발행 쌍(정탐 — 잡으라고 만든 케이스), 오마이뉴스 출구조사 쌍(오탐, 아래).
- 후보 34,313 → 확정 2 는 의도된 모양 — 후보 단계는 넓게, 검증이 거의 다 거른다.

## 5. 알려진 한계

- **정형 기사**: 출구조사처럼 지역구·숫자만 다른 템플릿 기사가 containment 로 접힌다(실측 1건).
  문턱을 올리면 진짜 전재를 놓치므로 STEP 1 에서 고치지 않고, STEP 4 정형 기사 판별 몫으로 넘긴다.
  골드셋 라벨링 때 정형 기사 사례로 전달.
