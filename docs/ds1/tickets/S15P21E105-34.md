# S15P21E105-34 · 이슈 카테고리 결정 (구성 기사 다수결)

| 항목 | 내용 |
|---|---|
| 상태 | 다수결 배포·실측 완료(9/14, 이슈 라벨률 100%) + 팀 어휘 8개 반영(9/15, §5) — 머지 후 EC2 재빌드 |
| 결과물 | `issue_summary.category` 컬럼, `feed/category.py`(`normalize_category`·`majority_category`), export 의 category 가 이 값을 우선 |
| 관련 티켓 | 90(issue_summary), 122(export), DE 61(수집 카테고리 매핑 — 이 티켓의 재료) |

## 1. 티켓 해석

FE 는 카테고리 탭으로 이슈를 필터하는데, 이슈 카테고리는 지금까지 **대표 기사 한 건의
값**이었다. 9/11 실측에서 gold 의 기사 category 가 4,704건 전부 OTHER 로 드러났고
(원인 둘: DE 매핑 부재 + 68%는 수집 피드에 섹션 정보가 없음), DE 가 매핑을 붙인 뒤
(61, 9/14) 기사 단위로는 30% 안팎만 라벨될 전망이었다. 대표 기사 하나에 의존하면 그
30% 확률로 이슈 카테고리가 정해지는 셈 — 구성원 전체를 보면 훨씬 자주 채울 수 있다.

## 2. 결정

| 결정 | 이유 |
|---|---|
| 이슈 카테고리 = 구성 기사 다수결 (OTHER·빈값 제외) | 이슈(평균 7건)에 라벨 기사가 하나라도 있으면 채워진다 — 기사 30% 라벨이어도 이슈 단위 커버리지 \~93% (1−0.7⁷) |
| 동률이면 대표 기사 값 우선, 라벨 0건이면 대표 기사 값 | 대표 기사는 이슈 중심 최근접이라 가장 그럴듯한 기본값 |
| `issue_summary` 컬럼으로 저장 + export 가 우선 사용 | DE gold_issue_feed 가 대표 기사 조인 대신 바로 읽을 수 있고(계약 §2), ds_output 도 같은 값 → 두 경로가 일치 |
| 어휘 정제는 하지 않음 (9/14) → 팀 어휘 확정 뒤 이슈 단위에서만 맞춤 (9/15, §5) | 카테고리 **값의 어휘**(국제 vs 세계, 연예·스포츠가 FE 탭에 없음)는 DE·BE·FE 가 한 표로 맞출 문제였고, 팀이 8개로 확정한 뒤 별칭만 이슈 단위에서 합친다 |

## 3. 검증

- 테스트 2개(다수결 규칙 5케이스, 파이프라인 통합 — 대표가 OTHER 여도 구성원으로 채움).
  전체 319 통과
- 로컬 1월 1/2 창(이슈 509, 스크래치 루트): **기사 단위 라벨률 86.9% → 이슈 단위 99.0%**.
  2023 데이터셋은 기사 라벨률이 높아 상승폭이 작지만, 실수집(기사 \~30%)에서는 격차가
  훨씬 크다 — 배포 후 오늘 창으로 재측정
- 부수 관찰: 2023 데이터엔 '최신기사' 같은 섹션 이름이 카테고리로 55건 — 어휘 정제가
  상류 몫이라는 근거
- 배포 실측(9/14 오늘 창): 이슈 325개 **라벨률 100%**(경제 105·사회 85·정치 39·국제 29·
  연예 27…). DE 어휘에 '산업'·'IT과학' 이 있어 FE 탭과 불일치 → 팀 안건으로

## 5. 어휘 확정과 반영 (2026-09-15)

팀 결정: 카테고리는 **정치·경제·사회·국제·연예·스포츠·문화·IT/과학** 8개, 산업은 경제로
합친다. FE 탭도 이 8개로 맞춘다(IT → IT/과학, 세계 → 국제).

| 결정 | 이유 |
|---|---|
| 정규화는 이슈 단위(`feed/category.py`)에서, 기사 원문 `gold.category` 는 그대로 | 원본 보존 원칙. 어휘가 또 바뀌면 `ALIASES` 한 곳만 고치고 feed 만 다시 돌린다 |
| 별칭을 다수결 표 집계 전에 합친다 | `산업`·`경제` 가 갈라져 표가 나뉘면 다수결이 틀어진다 |
| 어휘에 없는 값은 그대로 둔다(OTHER 로 안 삼킴) | 새 라벨이 들어온 것이 산출에 보여야 고칠 수 있다. 2023 데이터의 '최신기사' 55건이 그 예 |
| DE 수집 매핑도 같은 어휘로 맞추기를 권장 | DS1 정규화는 안전망 — 상류가 맞추면 여기서는 항등 |

`ALIASES`: `산업 → 경제`, `IT과학 → IT/과학`. 계약 §2 에 어휘 명시. 테스트: 별칭 합산 다수결·
대표 값 정규화·미지 값 통과·빈값 OTHER (+9, 전체 367).
