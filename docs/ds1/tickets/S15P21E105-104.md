# S15P21E105-104 · Golden Set 채점 스크립트·기준값 조정 실험

| 항목 | 내용 |
|---|---|
| 상태 | 채점 스크립트·시트 생성기 완성(파일럿으로 검증). 본 채점은 라벨링 주간 뒤 |
| 결과물 | `scripts/score_goldenset_clusters.py`·`score_goldenset_dedup.py`·`make_goldenset_sheets.py` |
| 관련 티켓 | 103(라벨 가이드), 10(dedup recall 미측정), 89·93(군집·문턱이 채점 대상) |

## 1. 티켓 해석

골드셋 = 사람이 만든 정답지. 파이프라인 출력(학생 답안)과 비교해 점수를 내고,
그 점수로 문턱값들(구제·배정 0.85, min_cluster_size 등)을 조정한다. 채점 과목 둘:

1. **군집**: 사람이 기사를 이슈로 묶은 라벨 vs issue_quality 배정 — **ARI**
2. **중복**: 사람이 기사 쌍을 O/X 판정 vs dedup 같은-그룹 여부 — **precision·recall**
   (precision 은 280쌍으로 쟀고 **recall 이 이번 목표**)

## 2. 스크립트

| 스크립트 | 하는 일 |
|---|---|
| `make_goldenset_sheets.py` | 라벨링 시트 생성. ① 군집 시트(하루 대표 기사 표본, 발행순, 라벨러 수만큼 복사) ② 중복 쌍 시트(**임베딩 유사도 상위인데 dedup 이 안 접은 쌍** = 놓쳤을 법한 후보 + 아래 띠 표본). 제목 포함이라 산출물은 local/ 전용 |
| `score_goldenset_clusters.py` | 라벨 CSV(파일럿 형식: article_id·labeler·cluster) → 쌍 득표 과반 합의 → ARI. **라벨러 간 일치도(평균 쌍별 ARI)** 도 함께 — 골드셋 자체의 신뢰도 |
| `score_goldenset_dedup.py` | 쌍 라벨 CSV → tp/fn/fp/tn, precision·recall·F1 |

## 3. 검증

- **군집 채점기 ↔ 파일럿 재현**: 30건을 전체 파이프라인(e5→UMAP→HDBSCAN)으로 돌려
  채점 → **ARI 0.8495** (티켓 89 의 0.850 재현). 라벨러 간 일치도 0.878
- **중복 채점기**: 자명한 쌍(접힌 쌍 10 = O, 무작위 10 = X)으로 precision/recall 1.0 확인
  — 이 스모크가 pandas NaN 버그(결측 duplicate_of 의 `is None` 검사 뚫림)를 잡아냄
- **시트 생성기**: 1/2 창 스모크. recall 후보 상위가 유사도 1.0인데 안 접힌 쌍들 =
  **min_fold_len(본문 100자 미만) 게이트로 의도적으로 안 접은 기사들**(영상·알림 류) —
  라벨링 주간에 사람이 판정할 정확한 지점

## 4. 라벨링 주간 운영 (팀 안내)

1. 표본 날짜 확정(실버 수집분 권장 — 서비스 분포와 동일) → 시트 생성해 배포
2. 군집 시트: 각자 cluster 칸에 이슈 번호 기입(형식 자유), 기준은 [LABEL_GUIDE.md](LABEL_GUIDE.md)
3. 중복 쌍 시트: O/X — 280쌍 검수와 같은 방식, 분담 + 20% 교차
4. 제출본으로 채점 → 문턱 조정 실험(창 크기·min_cluster_size·0.85들)
