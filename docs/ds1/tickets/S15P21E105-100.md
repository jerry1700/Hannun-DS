## 1. 티켓 해석

"본문 전처리 규칙 구축"은 **Gold 의 원문 `content` 에서 기사가 아닌 것(저작권 꼬리·기자 서명·방송 원고 마커·사진
출처·안내문)을 지우고, 문장 경계가 무너진 곳을 고쳐, 뒤 단계가 그대로 쓸 수 있는 `content_clean` 을 만든다**로
해석했다. 원문은 건드리지 않는다 — 규칙이 틀렸을 때 되돌릴 수 있어야 하고, 원문 그대로가 필요한 단계(중복 검출의
SHA-256)가 있기 때문이다.

"원문 데이터 재검증"은 두 가지로 했다. (1) SSAFY 과거 기사 CSV 283만 건을 훑어 구조·품질을 확인
([DATASET_PROFILE.md](../DATASET_PROFILE.md)). (2) DE 가 올린 `article_v1.json` 과 우리 `CommonArticle` 을 대조해 어긋난 곳을
고쳤다 — `source_type=HTML` 허용, `article_id` 해시의 URL 정규화.

## 2. 결정과 이유

| 결정 | 이유 |
|---|---|
| 정제 결과를 Gold 컬럼이 아니라 **별도 `clean/` 테이블**에 둔다(`article_id` 로 조인) | 규칙이 바뀌면 clean 만 다시 만들면 된다. ingest 와 preprocess 를 서로 모르는 채 돌릴 수 있고, Gold 스키마가 안 바뀌어 이미 쌓인 파티션과 충돌하지 않는다 |
| 파티션은 Gold 와 같은 `published_date`, 파티션 단위로 **통째로 다시 쓴다** | 같은 Gold + 같은 규칙이면 같은 파일. 부분 갱신 로직이 없어 단순하다 |
| 규칙은 코드 안의 **언론사 × 패턴 표**(`rules.py`), 적용 순서는 엔티티 → 인라인 → 저작권 꼬리 → 줄 → 꼬리 줄 → 마지막 줄 안 → 공백 | 순서가 결과를 바꾼다. 엔티티를 먼저 풀어야 `amp;` 가 섞인 문구가 걸리고, 저작권 꼬리를 잘라야 그 앞의 서명이 줄 끝에 온다 |
| 저작권은 "줄 삭제"가 아니라 **시작 표지부터 줄 끝까지 자르기** | 파이낸셜뉴스·머니S·뉴스1은 기사 전체가 한 줄이라 줄을 지우면 기사가 통째로 사라진다(첫 시도에서 82건이 비었다) |
| 서명 줄 규칙은 **단어 셋까지**, 인라인 서명은 이름 뒤 직함을 아는 것만 허용 | "이번 행사를 기획한 사람은 김민지 기자" 같은 문장을 지우지 않게. 본문 문장은 마침표로 끝나므로 단어 사슬이 거기서 끊긴다 |
| 마지막 줄 안 규칙은 **더 지워지는 게 없을 때까지 반복** | 사진 출처를 지우면 그 앞의 서명이 드러난다. 꼬리 줄도 마찬가지(연합뉴스는 이메일·제보·날짜 석 줄) |
| `sentence_space`: 한글 뒤 `.!?` 다음에 한글·숫자·따옴표가 바로 오면 공백 삽입 | KBS·뉴스1 원문은 문장 사이 공백이 없다(`삭감했습니다.대구시는`). DS2 `split_sentences` 가 `\s+` 를 요구해서 이대로면 한 문장으로 붙는다. 앞이 한글일 때만 봐서 `24.7%`·`U.S.` 는 안 건드린다 |
| 상태 `ok` / `short`(< 100자) / `empty` | 100은 DE 크롤러가 발행 전에 버리는 기준과 같다. short 는 사진기사·속보, empty 는 원문이 서명·저작권만이던 것 |
| `rules_applied` 를 행마다 남기고 `rules_version` 을 박는다 | 어떤 규칙이 뭘 지웠는지 되짚을 수 있어야 규칙을 고칠 수 있다 |
| URL 정규화는 **추적 파라미터만 제거**(DE 는 쿼리 전체 제거) | 디지털타임·국민일보·SBS 는 쿼리가 기사 번호. 차이는 계약 문서로 DE 와 조정 |

## 5. 미결

- [ ] `crawled_at` 을 Gold 에 저장할지
- [ ] 정형 기사(시황·운세·사진 모음·출연자 목록)를 어디서 거를지 — 여기가 아니라 STEP 4 로 넘긴다

## 6. 재현

```bash
# 실데이터 표본 → Gold → clean (전부 local/, 커밋 안 함)
python scripts/csv_to_common_jsonl.py ../../../ssafy_dataset_news_2023.csv ../../../ssafy_dataset_news_2024_1st_half.csv \
    --per-publisher 100 -o local/dataset_sample.jsonl
hannun-ingest --input local/dataset_sample.jsonl --gold-root local/gold
hannun-preprocess --gold-root local/gold -v
```

정제 결과는 `CleanStore("local/gold").read()` 로 읽고 `GoldStore("local/gold").read()` 와 `article_id` 로 조인한다.
