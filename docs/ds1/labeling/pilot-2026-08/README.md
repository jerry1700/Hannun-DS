# 라벨링 파일럿 — 6명 × 30건 (2026-08-24)

팀원 6명(L6·L5·L2·L4·L3·L1)이 같은 기사 30건을 서로 상의 없이
이슈로 묶고 기사마다 긍정/부정/중립을 찍었다. 라벨 가이드(S15P21E105-103)를 쓰기 전에
"기준 없이 하면 어디서 갈리는가"를 보려는 것이었다.

도구에는 32건이 들어 있었고 2건(소상공인 전기요금 감면, `7c5a35e8`·`c8be1d35`)은 해시

갈린 원인은 두 가지고, 둘 다 "기준을 안 지켜서"가 아니다.

**① 논제가 정해져 있지 않았다.** 기준은 "논제를 지지하면 긍정"인데 논제를 무엇으로 잡는지가
사람마다 달랐다.

- 용산공원: L5은 논제를 "용산공원에 주택을 공급한다"로 잡아 청와대·하정우 기사를 긍정,
  오세훈 기사(`a19fbebd`)를 부정으로 찍었다. L4은 그룹 이름을 "용산공원 부지 활용 —
  오세훈은 반대"로 붙이고 오세훈 기사를 긍정, 청와대·한병도 기사를 부정으로 찍었다.
  **같은 규칙을 따랐는데 라벨이 정반대다.**
- 조희대: L1은 서영교 "사퇴하라"(`8ce58929`)·송영길 "탄핵"(`360aef06`)·김민석 기사를 긍정으로,
  L6·L5·L4은 부정으로 찍었다. L1은 논제를 "조희대 사퇴·탄핵"으로, 나머지는
  "조희대의 제청 행위"로 잡은 것이다.

**② "사실 전달"과 "지지 내용이 중심"의 경계.** 정부 발표 전달 기사, 정치인 발언 인용 기사를
L2(26/30 중립)·L3(23/30 중립)은 사실 전달로, L5(10/30 중립)·L4(8/30 중립)은
인용된 주장이 기사의 중심이라고 읽었다. 기존 스탠스 가이드(`news/docs/라벨가이드_스탠스.md`)의
미결 경계 사례 3번(발표·해명 전달)과 4번(정치 공방 인용)이 그대로 재현됐다.

## 가이드에 반영할 것

- 이슈마다 **논제를 문장 하나로 먼저 쓴다**. 스탠스 라벨러는 그 문장에 대한 찬반만 판단한다.
  이 한 줄이 있었으면 ①은 생기지 않았다. (스탠스는 DS2 몫이라 전달 필요)
- 이슈 묶음 규칙 후보: **한 이슈 = 하나의 결정·행위 + 그에 대한 반응·해명·후속**. 이 기준이면
  노경필 해명은 조희대 이슈에 들어가고, 정상회담 추진은 별개 결정이라 별도 이슈다.
  3:3 사례를 이 기준으로 팀에 다시 묻는다.
- 발표 전달·인용 기사의 스탠스 처리는 팀이 방향을 정해야 한다. 개인이 더 잘 읽어서 해결되지 않는다.
