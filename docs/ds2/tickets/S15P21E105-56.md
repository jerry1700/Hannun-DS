## 1. 목적

DS1에서 전달되는 이슈 데이터를 받아 DS2 출력 형태로 변환하는
더미 모듈을 구현한다.

실제 중분류·소분류 알고리즘 적용 전,
DS1 → DS2 입출력 구조와 스키마 검증 흐름을 확인하는 단계다.

## 2. 처리 흐름

```text
DS1 이슈 데이터
→ 입력 스키마 검증
→ DS2 더미 결과 생성
→ 출력 스키마 검증
→ 결과 반환
```

현재 기사별 `stance`는 `neutral`,
`stance_confidence`는 `null`을 사용한다.

`event_name`, `fact_summary`, `viewpoint_analysis` 역시
실제 분석 결과가 아닌 더미값이다.

## 3. 구성

```text
src/hannun/enrichment/
├─ __init__.py
├─ pipeline.py
└─ schema.py
```

- `pipeline.py` : DS1 입력 → DS2 더미 출력 흐름
- `schema.py` : DS1 입력 및 DS2 출력 형식 검증

DS1 → DS2 전달 데이터 상세 구조는
`docs/ds2/interface_ds1_to_ds2.md`에 정리한다.

## 4. 실행

`data/ds/`에서 실행한다.

```bash
./.venv/Scripts/python.exe -m hannun.enrichment.pipeline
```

샘플의 첫 번째 이슈를 입력받아 DS2 더미 결과를 출력한다.

## 5. 테스트

```bash
./.venv/Scripts/python.exe -m pytest tests/test_enrich_dummy.py -v
```

현재 테스트 3개:

- 정상 DS1 입력 처리
- 필수 `issue_cluster_id` 누락 검증
